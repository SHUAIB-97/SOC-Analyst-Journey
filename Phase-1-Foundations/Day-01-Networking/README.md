# Network Fundamentals for Security Operations

## Overview
This module covers foundational networking concepts relevant to Security Operations Center (SOC) monitoring and investigation.

## Technical Areas
- Network architecture: LAN and WAN
- Network devices: switches and routers
- IP addresses and MAC addresses
- Common ports and network services
- DNS resolution and network troubleshooting
- TCP and UDP fundamentals

## Tools and Practical Exercises
Windows command-line utilities used to explore network configuration and name resolution:

- `ipconfig /all` — inspect local network configuration.
- `nslookup example.com` — examine DNS name resolution.
- `ping example.com` — test basic connectivity.
- `tracert example.com` — inspect the route taken toward a destination.

## Security Operations Relevance
Networking knowledge helps SOC analysts investigate suspicious connections, unusual communication patterns, DNS activity, and potential network threats.

## Investigation Focus
When reviewing network activity, consider:
- Source and destination IP addresses
- Destination ports and protocols
- DNS queries and responses
- Unexpected or unusual connections

## Learning Outcomes
Developing foundational knowledge of network communication and its application to security monitoring and investigation.
